# Java Service & Unit Testing Suite

A Java-based service application developed to practice object-oriented programming, software testing, and requirement validation using JUnit 5.

## Project Overview

This project includes contact, task, and appointment management services. Each service was developed from defined software requirements and includes validation rules to help ensure that invalid data is rejected.

The project also includes JUnit 5 test cases used to verify service functionality and confirm that application requirements are met.

## Features

- Create, update, and delete contact records
- Create, update, and delete task records
- Create and delete appointment records
- Validate required fields and input lengths
- Prevent invalid or null values
- Verify unique identifiers
- Test expected and invalid application behavior

## Technologies

- Java
- JUnit 5
- Eclipse
- Object-Oriented Programming
- Unit Testing
- Software Testing

The project helped me understand how testing can identify defects early and verify that software behaves according to defined requirements.
